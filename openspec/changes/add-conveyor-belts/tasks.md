## 5. Проверки

- [ ] 5.1 Ячейка сыпучего едет по ленте в сторону её переноса, а на встречной ленте — в противоположную
- [ ] 5.2 Реголит, пульпа, иридий и шлак едут одинаково: правило не смотрит на вид вещества
- [ ] 5.3 Одиночная ячейка на ленте не сваливается вбок при свободных диагоналях
- [ ] 5.4 На куче поверх ленты едет только подошва, верхние слои скатываются как обычно
- [ ] 5.5 Упор собирает очередь: ни одна ячейка не пропала, не прошла сквозь упор и не вытекла вбок
- [ ] 5.6 Снятие упора возобновляет ход, число ячеек в очереди не изменилось
- [ ] 5.7 Разрыв в ленте останавливает груз, достройка пропущенной ячейки его возобновляет
- [ ] 5.8 За один шаг ни одна ячейка не смещается по горизонтали больше чем на одну позицию
- [ ] 5.9 Груз едет на длинном прогоне и не застывает после первой паузы темпа
- [ ] 5.10 Мир с пустой лентой обходит ноль ячеек за шаг
- [ ] 5.11 Вставшая гружёная лента, в которой ничего не двигается, тоже обходит ноль ячеек
- [ ] 5.12 Сумма ячеек каждого материала не меняется после многих шагов на гружёной ленте
- [ ] 5.13 Одинаковая последовательность шагов дважды из одного состояния даёт идентичные сетки
- [ ] 5.14 Конвейер не берётся кистью копания, не собирается пылесосом и не вытесняется ничем
- [ ] 5.15 Лента ставится над пустотой, машина без опоры — не ставится
- [ ] 5.16 Лента из N ячеек списывает ровно N цен ячейки; при нехватке средств постановка отвергается целиком и счёт не уходит в минус
- [ ] 5.17 Снос ячейки ленты возвращает цену ячейки и не трогает соседние; груз, лежавший на ней, остаётся в мире
- [ ] 5.18 Применение по ленте другого направления сносит её, а не заменяет
- [ ] 5.19 Лента доносит пульпу до приёмной грани сепаратора, и та поглощает её без нового правила
- [ ] 5.20 Лента доносит иридий до зоны приёмника модуля, кредиты начисляются без действий игрока
- [ ] 5.21 Сквозной прогон: сепаратор выдаёт продукт на ленту, лента доводит его до модуля, счёт растёт сам
- [ ] 5.22 Шлак доезжает вместе с иридием и остаётся лежать в зоне приёмника
- [ ] 5.23 Прогнать весь существующий набор: автомат, реакции, чанки, копание, сбор, приёмник, здания, движение, полёт, камера, звук
