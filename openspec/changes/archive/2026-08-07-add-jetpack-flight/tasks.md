## 2. Тяга

- [x] 2.1 Ввести в `Player` признак «тяга применена в этом шаге» и сбрасывать его в начале каждого шага
- [x] 2.2 Применять тягу при удержании клавиши прыжка и скорости подъёма ниже предела ранца; проверки «на земле ли персонаж» не добавлять
- [x] 2.3 Ограничить скорость подъёма пределом ранца, оставив предел скорости падения прежним
- [x] 2.4 Убедиться, что сразу после прыжка тяга не применяется, пока гравитация не снизит скорость подъёма до предела ранца
- [x] 2.5 Выбирать ускорение вбок по трём состояниям: на земле / тяга работает / свободное падение
- [x] 2.6 Убедиться, что обрезка прыжка срабатывает только на отпускании и не конфликтует с тягой
