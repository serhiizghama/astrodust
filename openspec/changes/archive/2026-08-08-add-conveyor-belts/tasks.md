## 5. Проверки

- [x] 5.1 Ячейка сыпучего едет по ленте в сторону её переноса, а на встречной ленте — в противоположную
- [x] 5.2 Реголит, пульпа, иридий и шлак едут одинаково: правило не смотрит на вид вещества
- [x] 5.3 Одиночная ячейка на ленте не сваливается вбок при свободных диагоналях
- [x] 5.4 На куче поверх ленты едет только подошва, верхние слои скатываются как обычно
- [x] 5.5 Упор собирает очередь: ни одна ячейка не пропала, не прошла сквозь упор и не вытекла вбок
- [x] 5.6 Снятие упора возобновляет ход, число ячеек в очереди не изменилось
- [x] 5.7 Разрыв в ленте останавливает груз, достройка пропущенной ячейки его возобновляет
- [x] 5.8 За один шаг ни одна ячейка не смещается по горизонтали больше чем на одну позицию
- [x] 5.9 Груз едет на длинном прогоне и не застывает после первой паузы темпа
- [x] 5.10 Мир с пустой лентой обходит ноль ячеек за шаг
- [x] 5.11 Вставшая гружёная лента, в которой ничего не двигается, тоже обходит ноль ячеек
- [x] 5.12 Сумма ячеек каждого материала не меняется после многих шагов на гружёной ленте
- [x] 5.13 Одинаковая последовательность шагов дважды из одного состояния даёт идентичные сетки
- [x] 5.14 Конвейер не берётся кистью копания, не собирается пылесосом и не вытесняется ничем
- [x] 5.15 Лента ставится над пустотой, машина без опоры — не ставится
- [x] 5.16 Лента из N секций списывает ровно N цен секции; при нехватке средств постановка отвергается целиком и счёт не уходит в минус
- [x] 5.17 Снос секции ленты возвращает цену секции и не трогает соседние; груз, лежавший на ней, остаётся в мире
- [x] 5.18 Применение по ленте другого направления сносит её, а не заменяет
- [x] 5.24 Секция встаёт по сетке: прицел в любую точку клетки даёт одно и то же место
- [x] 5.25 Соседние секции стыкуются без зазора и без нахлёста, груз переходит между ними
- [x] 5.26 Персонаж проходит сквозь ленту и сквозь корпус сепаратора, но упирается в корпус модуля
- [x] 5.27 Постройка ставится поверх хитбокса персонажа и не мешает ему двигаться
- [x] 5.28 Груз лежит на верхнем ряду секции и не проваливается сквозь проходимый корпус
- [x] 5.29 Продукт сепаратора доезжает до модуля по ленте, проложенной ПОД машиной, а не внутри окна
- [x] 5.19 Лента доносит пульпу до приёмной грани сепаратора, и та поглощает её без нового правила
- [x] 5.20 Лента доносит иридий до зоны приёмника модуля, кредиты начисляются без действий игрока
