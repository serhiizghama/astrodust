## 6. Проверки

- [ ] 6.1 Иридий в зоне приёмника даёт очки и не даёт кредитов; реголит и пульпа — наоборот
- [ ] 6.2 Шлак в зоне приёмника не даёт ни одной валюты и остаётся в мире
- [ ] 6.3 Ни один счётчик не уходит в минус на длинной последовательности сдач и покупок
- [ ] 6.4 Покупка списывает очки ровно один раз; повторная покупка ничего не списывает
- [ ] 6.5 Покупка при нехватке очков отвергается целиком, счётчик не меняется
- [ ] 6.6 Технология с неоткрытой предпосылкой не покупается при любом количестве очков; после открытия предпосылки покупается
- [ ] 6.7 Купленная технология параметра меняет поведение инструмента со следующего применения
- [ ] 6.8 Купленная технология конвейера добавляет оба направления в перебор каталога
- [ ] 6.9 До покупки конвейер отсутствует в переборе и не ставится никаким способом
- [ ] 6.10 Каталог не пуст в начале партии
- [ ] 6.11 Без покупок профиль настроек совпадает с конфигом; весь существующий набор проверок проходит без изменений
- [ ] 6.12 При всех открытых технологиях предел скорости подъёма строго ниже импульса прыжка и заметно ниже предела падения
- [ ] 6.13 При всех открытых технологиях радиус кисти сбора много меньше полуширины кадра
- [ ] 6.14 Базовый радиус кисти сбора не превышает радиуса кисти копания
- [ ] 6.15 Одинаковая последовательность шагов симуляции с открытыми технологиями и без них даёт идентичные сетки
- [ ] 6.16 При открытом оверлее клавиши движения не двигают персонажа, а применение инструмента не меняет мир
- [ ] 6.17 Зажатая в момент открытия клавиша бега не оставляет персонажа бегущим
- [ ] 6.18 При открытом оверлее симуляция продолжается: машина выдаёт порции, вещество оседает
- [ ] 6.19 Весь цикл «открыть оверлей — выбрать — купить — закрыть» проходится без мыши
- [ ] 6.20 Прогнать весь существующий набор: автомат, реакции, чанки, копание, сбор, приёмник, здания, конвейеры, движение, полёт, камера, звук
