## Context

Сейчас деньги рисуют четыре независимых куска кода (см. proposal.md — Why):
`drawCredits` в `render/hud.ts` (значок + число), заголовок оверлея, подпись
цены под узлом и цена в полосе сведений в `render/overlay.ts` (число со знаком
`₡`), а строку «нужно ещё N ₡» собирает `statusNote` в `progress/research.ts`.
Тон `RAMP.warm[4]` записан дважды.

Ограничения, которые задают решение:

- **Зависимости идут вниз по карте `CLAUDE.md`.** `render/` видит `progress/`,
  обратного пути нет: общий вид суммы, положенный в рендер, слою прогресса
  недоступен в принципе.
- **Значок пиксельный.** `UiSurface.icon` выводит спрайт один в один, ячейка
  в пиксель, и растянуть его дробным множителем нельзя — сетка сомнётся.
- **Ширина надписи измеряется, а не вычисляется** (`ui-layer`): сумма участвует
  в раскладке наравне с текстом, значит её ширину обязан отдавать тот же путь.
- **Импорт из чужой подсистемы — только через `index.ts`**, внутри подсистемы
  файлы импортируют друг друга напрямую.

## Goals / Non-Goals

**Goals:**

- Один модуль, знающий, как выглядит денежная сумма: значок, тон, порядок,
  просвет, измерение ширины.
- `hud.ts` и `overlay.ts` перестают знать про значок монеты и тон валюты.
- Знак `₡` исчезает из интерфейса и из `progress/`.

**Non-Goals:**

- Новые значки, второй размер монеты, анимация счётчика.
- Группировка разрядов и любое другое изменение формата числа: сейчас это
  десятичная запись без разделителей, такой она и остаётся.
- Пересмотр цен, тонов состояния покупки и раскладки дерева.

## Decisions

### Вид суммы — модуль `src/render/credits.ts`, а не часть `render/ui/`

Слой `render/ui/` — общая поверхность, типографика и токены вида; его `skin.ts`
прямо оговаривает, что смысловые цвета остаются рядом с тем, что их назначает.
Валюта — смысл игры, а не свойство слоя: поверхность обязана уметь рисовать
значок и надпись, но не обязана знать, что такое кредит.

Поэтому модуль лежит в `render/` рядом с `hud.ts` и `overlay.ts`, и оба
импортируют его напрямую — это одна подсистема, глубокого импорта здесь нет.
`render/index.ts` пополняется, только если модуль понадобится снаружи; сейчас
не нужен.

Альтернатива «положить в `ui/skin.ts`» отвергнута: тогда набор общих токенов
начинает знать про валюту, и следом туда переедут состояние покупки и цвета
материалов.

### Поверхность модуля

```
CREDITS_TONE                                  тон валюты, единственная запись
measureCredits(ui, amount, style): number     ширина «значок + просвет + число»
drawCredits(ui, amount, x, y, style): number  рисует и возвращает ту же ширину
```

- `style` — обычный `TextStyle` из шкалы (`smallText` / `bodyText` /
  `titleText`). Кегль, начертание, ореол и выравнивание задаёт **место**, форму
  суммы — модуль. Так счётчик в углу остаётся с ореолом (лежит на мире), а цена
  под узлом — без него (лежит на подложке).
- Тон берётся из `style.color`. По умолчанию места подставляют `CREDITS_TONE`;
  цена под узлом сознательно подставляет тон состояния покупки — спека
  `research` требует, чтобы состояние продолжало читаться цветом.
- Выравнивание модуль разбирает сам: он знает полную ширину группы, поэтому
  `right` прижимает к `x` правый край числа, `center` центрирует всю группу
  вместе со значком. Внутри число всегда рисуется от левого края группы.
- Возврат ширины обязателен: сумма стоит в строке рядом с другими словами
  («нужно ещё …») и внутри отведённого места (шаг колонки, ширина полосы).

### Значок одного размера, выровненный по строке

Монета остаётся 7×7 и не масштабируется: единственный допустимый множитель —
целый, а кегли шкалы (6 / 7.5 / 9) целых множителей не дают. Вместо этого
модуль ставит значок по вертикали от кегля строки — смещение считается из
`style.size` и высоты спрайта, а не подбирается по месту, как сейчас в
`drawCredits` (`+1` руками).

Альтернатива «второй спрайт монеты под заголовочный кегль» отвергнута:
два значка одной валюты — это ровно то, что чинит эта работа.

### Просвет значка и числа переезжает в `UI`

`HUD.counterGap` описывал просвет счётчика; теперь это свойство общей формы,
а не панели. Число переезжает в `UI` (рядом с остальными токенами вида)
и удаляется из `HUD`. `HUD.counterMargin` остаётся: это отступ счётчика от
угла кадра, свойство места.

### Причина недоступности приходит из `progress/` значением, а не строкой

`statusNote` перестаёт возвращать готовую строку и возвращает размеченное
значение:

```
type TechNote =
  | { kind: 'none' }
  | { kind: 'short'; amount: number }     // сколько ещё нужно
  | { kind: 'locked'; missing: string[] } // какие предпосылки не открыты
```

Правило «какая именно причина» остаётся в `progress/` — там же, где считается
статус, и по-прежнему проверяется без браузера. Слова («нужно ещё …»,
«требует: …») и обозначение суммы становятся делом рендера, который тоже
проверяется без браузера — через журнал поверхности. Знака валюты в `progress/`
не остаётся, а рендер получает число, из которого может нарисовать сумму общим
видом; из строки — не мог бы.

`OverlayNode.note` меняет тип со `string` на `TechNote`. Второе поле рядом со
строкой (`note` + `shortfall`) отвергнуто: два способа выразить одну причину —
та же болезнь, что и два обозначения одной валюты.

Строка причины в полосе сведений собирается из слова и суммы: слово
обрезается по месту, сумма — нет. Обрезать сумму бессмысленно — ради неё
строка и написана.

## Risks / Trade-offs

- **Цена под узлом становится шире** (значок вместо буквы) → ширина считается
  через `measureCredits` и подгоняется под шаг колонки тем же путём, что и
  название; проверка на длинное название уже есть.
- **Монета 7×7 у мелкого кегля 6 выглядит крупнее буквы** → принято сознательно:
  единственный значок валюты важнее полупиксельной соразмерности, а дробный
  масштаб испортил бы его сетку.
- **Смена типа `OverlayNode.note` задевает `main.ts`, `overlay.ts` и проверки
  `research`** → тип меняется в одном месте, `tsc --noEmit` находит всех
  читателей; молчаливой поломки здесь быть не может.
- **Снимки интерфейса меняются** (`npm run shot:ui`) → пересняты в рамках
  задачи; стоимость кадра сверяется с прежним замером, чтобы лишние значки
  не утащили кадр за шаг.
