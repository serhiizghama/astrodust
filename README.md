# ASTRODUST

Браузерная 2D пиксельная игра: космонавт высаживается на небесное тело, копает
полностью разрушаемый мир и перерабатывает породу в автоматизированную фабрику.

**Каждый пиксель — это материал со своей физикой.** Мир не тайлмап: коллизия
считается по пикселям, поэтому разрушаемость и осыпание песка получаются
бесплатно. Жанрово — *Noita × Factorio*; механики вдохновлены
[Sandustry](https://store.steampowered.com/app/2764460/Sandustry/), сеттинг и
названия свои.

Статус: MVP реализован — космонавт ходит по Луне, копает реголит, звук
генерируется процедурно.

## Стек

TypeScript + Vite, рендер в `<canvas>` через `ImageData` с целочисленным
апскейлом, звук — Web Audio API. Ноль рантайм-зависимостей: `dependencies`
пустые, всё игровое написано руками.

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
```

## Управление

| Клавиша | Действие |
|---|---|
| `A` / `D` или `←` / `→` | идти |
| `W` / `↑` | прыжок, удержание — ранец; заодно прицел вверх |
| `S` / `↓` | прицел вниз |
| `Space` или ЛКМ | копать |
| `M` | звук вкл/выкл |
| `F3` | отладочный оверлей |
| `Q` / `E` | отладка: выбрать вещество / поставить его |

## Скрипты

| Команда | Что делает |
|---|---|
| `npm run dev` | дев-сервер Vite |
| `npm run build` | typecheck + продакшн-сборка |
| `npm run typecheck` | только проверка типов |
| `npm test` | смоук-проверки ядра (Node, без браузера) |
| `npm run bench` | бенчмарк кадра рендера |
| `npm run shot` | скриншоты сцены через Playwright в `shots/` |
| `npm run verify:audio` | офлайн-рендер звука и проверка сигнала |
| `npm run format` | Prettier по `src`, `tests` и конфигам |

## Структура

```
src/
├─ main.ts        # бутстрап + игровой цикл
├─ config.ts      # ВСЕ константы в одном месте
├─ core/          # loop (fixed timestep), input, display
├─ render/        # renderer, camera, backdrop
├─ world/         # мир как Uint8Array: материалы, симуляция, копание, чанки
├─ entities/      # player
└─ audio/         # процедурный звук: context, soundscape, voices
```
