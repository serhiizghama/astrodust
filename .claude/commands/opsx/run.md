Запустить скилл `openspec-batch` для списка изменений: `$ARGUMENTS`

Аргументы — имена OpenSpec-изменений через пробел или запятую, в том порядке, в котором их
выполнять; плюс необязательные флаги `--dry-run` и `--commit`.

Если аргументов нет — показать активные изменения (`openspec list --json`) и спросить, какие
прогнать и в каком порядке. Не начинать работу с догадки о порядке.

Дальше действовать строго по `.claude/skills/openspec-batch/SKILL.md`: одно изменение за раз,
до архива, без вопросов между фазами, кроме перечисленных там жёстких остановок.
